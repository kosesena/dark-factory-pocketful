Visual direction for the browser interface (part of the task; the screens, components and code are yours to design and build)

Character: a calm, warm, handmade finance product. Think soft felt and paper rather than
glass and neon: friendly, trustworthy, unhurried. It must still read as a serious place to
keep money: clear numbers, clear actions, nothing playful in the money itself.

Palette (all text colours meet 4.5:1 on both backgrounds; keep it that way):
- Page background, warm cream: #F6EFE4
- Cards and inputs, light felt: #FFFBF5, with a soft #D9C9B3 edge and a gentle shadow
- Main text, deep brown: #3B2416. Secondary text: #6B5242
- Primary action and the spendable balance, moss green: #3E5A2D (white text on it)
- Held or reserved money, terracotta: #9A4A18
- States, each with its own tint background: success #2E6638, pending #7A5200,
  refused #A1322A, uncertain #6A4595, private #A8435C, informational #2F4E9A

Shape and material: generous rounded corners (about 14px on cards, fully rounded pills for
statuses and navigation), comfortable padding, a subtle stitched or dashed inner border is
welcome on cards as a felt detail, used sparingly. No gradients behind text.

Type: one humanist sans-serif with tabular figures for every amount; a clear scale (for
example 14 / 16 / 20 / 28 / 44px). The spendable amount is the largest number on the page.
Amounts right-aligned in lists. No web fonts fetched at run time.

Layout: one column at 375px with navigation that never wraps a label; two columns at desktop
widths where it helps scanning. Every status is a word plus a colour, never colour alone.
Empty, loading, error and uncertain states are designed, not default text.
